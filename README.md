💡 程式介紹
✏️ 請在此處簡述專案目標與背景。
  這是一個基於（使用的語言 C++）開發的遊戲。主要特色包含物件導向得核心觀念

📜 遊戲規則
✏️ 請列出遊戲的核心規則與判定方式。

  勝利條件： 玩家擊敗遊戲指定的敵人(有兩關)

  失敗條件： 生命值歸零、選擇錯誤

  特殊機制： 有血條、隨機的攻擊力、自行選擇攻擊、防禦、及渾身一擊(會有技能冷卻)、打過第一關會回復體力條、魔力或體力不足的話就無法放技能

🎮 玩法

操作方式： 藉由鍵盤輸入數字

遊戲流程：輸入數字來選擇採取的行動

程式啟動後，首先會看到
    =========================================
    歡迎來到簡易 RPG 戰鬥系統！
    =========================================
    請選擇你的職業：\n1. 法師 (使用魔力 MP)\n2. 戰士 (使用體力 SP)
    請輸入數字 (1 或 2): 

玩家需要根據畫面提示進行
    第一步 先選擇想玩的角色
    再來 選擇攻擊、防禦的攻擊模組
